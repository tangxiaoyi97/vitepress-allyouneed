# Showcase

This section demonstrates the **full set of capabilities** of `vitepress-allyouneed`, one by one. Every section is a **source + live render side-by-side**: the top shows you how to write the Markdown, and right below it is how this very page actually renders (this site itself runs the plugin — what you see is what you get).

> [!tip] How to use this section
> Want to copy the syntax? Just look at the code block in each section. Want to confirm the result? Look at the rendered output below the code block. Each section ends with the relevant config options and doc links.
