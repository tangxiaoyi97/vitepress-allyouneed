# TypeScript Utility Types

| Type | 作用 |
|---|---|
| `Partial<T>` | 所有字段变可选 |
| `Required<T>` | 所有字段变必选 |
| `Pick<T, K>` | 挑几个字段 |
| `Omit<T, K>` | 排除几个字段 |
| `Record<K, V>` | 键值对类型 |
| `ReturnType<F>` | 函数返回类型 |
| `Parameters<F>` | 函数参数 tuple |
