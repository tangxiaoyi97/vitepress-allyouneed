# Vite Plugin 钩子

常用钩子(按生命周期):

1. `config` — 修改/扩展 Vite 配置
2. `configResolved` — 配置定型后
3. `configureServer` — dev server 中间件
4. `resolveId` — 模块解析
5. `load` — 模块加载
6. `transform` — 模块转换
7. `handleHotUpdate` — HMR
8. `generateBundle` — build 输出

正在搭建的项目用了大部分,见 [[typescript-tips]]。
