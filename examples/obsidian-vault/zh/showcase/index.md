# 功能展示 Showcase

这一区把 `vitepress-allyouneed` 的**全部能力**逐个演示出来。每一节都是**源码 + 实际渲染对照**:上面给你看 Markdown 怎么写,下面就是这个页面真实渲染出来的效果(这个站本身就跑着插件,所见即所得)。

> [!tip] 怎么用这一区
> 想抄语法,直接看每节的代码块;想确认效果,看代码块下面的渲染结果。每节末尾给出相关配置项与文档链接。
