# v0.5 巡览

这一页是 v0.5 的"新东西速览"。想看每个功能的**完整源码 + 渲染对照**,去 [[showcase/index|功能展示区]]。

## v0.5 重点:主题集成彻底底层化

v0.5 的核心是让**第三方 VitePress 主题作者完全不用知道这个插件存在**:

- **全部 CSS 进 `@layer vitepress-allyouneed`** —— 你(或任何第三方主题)写的普通 CSS **自动赢**我们的样式,无论选择器权重或加载顺序。`.wikilink { color: red }` 就真的红,不用斗争。
- **删掉所有 `!important`** —— 不再需要,你 100% 能覆盖。
- **新 `defineTheme()` 工厂** —— 零配置一行接入,或 `defineTheme({ extends: 第三方主题 })` 嵌套别人的主题。

> [!success] 对你的影响
> 升级到 v0.5 后,如果你之前为了盖住插件样式写过 `!important` 或高权重 hack,现在大多可以删掉了 —— 普通 CSS 就能覆盖。

## 图谱体验升级

关系图([[views|看实际效果]])这一版更顺滑:

- 缩小时节点名**平滑淡出**、放大时浮现(和 Obsidian 一致);
- hover 节点**稳定命中**(加了透明命中圈,小节点也好点);
- 物理参数重调,拖拽 / 收敛不抖;
- 移动端高度自适应。

## 健壮性

- 视图数据加载做了完整字段校验,`vault-data.json` 损坏时优雅报错而不是整页崩;
- 日期统一 UTC 格式化,消除 SSR 水合不匹配;
- 死链预扫换成线性扫描,大 vault 不会因畸形输入卡死。

## 自上一版(v0.4)以来

- **`folderLinkOrder`** 取代旧的 `autoFolderIndex` —— 文件夹链接落点(`same-name` / `index` / `readme` / `first-file`)可精确控制,不再写 `index.md` 文件;
- **dev HMR 自动重启** —— 增删 `.md` 或改 `_sidebar.md` 后 sidebar / nav 立刻反映;
- **章节号锚点放宽** —— `[[note#13]]` 能匹配 `## 13) 标题`、`## 13: 标题` 等,但仍不误匹版本号 `13.5`。
