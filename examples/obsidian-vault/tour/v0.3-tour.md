# v0.3 feature tour

每个 v0.3 语法添加都在这里跑一遍,直接看渲染。

## Callouts(13 种 + 折叠)

> [!note] Note
> A plain note. Body 里可以 **markdown**、`code`、[[overview|wikilink]]。

> [!info] Info
> Info-style callout.

> [!tip] Tip[^1]
> Use ==highlights== inside.

> [!success] Success
> Looks good.

> [!question] Question
> What's the meaning of life?

> [!warning] Warning
> Heads up.

> [!failure] Failure / [!danger] Danger / [!bug] Bug
>
> > [!danger] Danger
> > Critical alert.

> [!example] Example / [!quote] Quote / [!abstract] Abstract / [!todo] Todo
>
> > [!quote] Quote
> > "Stay hungry, stay foolish."

## Highlight & comments

==高亮短语==,甚至 ==**bold inside a mark**== 也可以。

下面有 %%隐藏的行内注释%% 不会出现在输出里。

%%
整段块注释 —— 不会渲染。
%%

## Footnotes

Pandoc 风格脚注[^1],可以多次引用[^longer],并且复用[^1]同一个 id。

[^1]: First footnote — supports **bold** and `code`.
[^longer]: 另一条带较长 body 的脚注。同 id 多次引用会共享编号 + 多个反链。

## Block refs

这一段带稳定 anchor。^intro-block

可以通过 URL `#^intro-block` 跳到它。`^intro-block` 标记会被从渲染中剥除。

## #tag

正文里写 #showcase #v03 #demo,会自动链到 `/_perspectives_/tags#tag`。

> [!note] Tag 字符规则
> Obsidian 不允许 tag 含 `.` `,` `?` 等。带 `.` 的版本号(如 `v0.3`)写成 `v03`/`v0-3`/`v-0-3` 等都可以,或直接用 frontmatter `tags: [v0.3]`(frontmatter 字段无此限制)。

## Media embeds

(把对应的 .mp3 / .mp4 / .pdf 丢进 vault,直接 `![[clip.mp3]]` / `![[movie.mp4|640x360]]` / `![[doc.pdf|800x600]]` 就能渲染播放器 / iframe。)
