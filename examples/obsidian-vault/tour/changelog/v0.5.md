# v0.5 — Theme goes low-level + graph and robustness

## Theme integration (core)

- **All 7 CSS files move into `@layer vitepress-allyouneed`** — ordinary CSS from users / third-party themes automatically wins, regardless of specificity or load order.
- **All `!important` removed** — no longer needed; overriding is 100% feasible.
- **`defineTheme()` factory**: zero-config one-line setup, or `defineTheme({ extends: thirdPartyTheme })` to nest.
- The DocHeader banner title now uses `<div role="heading" aria-level="1">`, dodging VitePress's `.vp-doc h1` selector so the layered font size takes effect correctly.

## Graph experience

- Node names **fade out smoothly when zoomed out / emerge when zoomed in** (fixes the earlier bug where zoom labels didn't fade — the SVG `opacity` attribute was overridden by CSS, now driven by a CSS variable).
- **Stable hover hits**: a transparent hit ring is added (radius = max(visible+8, 12)), so even small nodes are easy to hit; the zoom feedback now uses `transform: scale`, which doesn't affect hit geometry.
- Physics parameters retuned (gentler convergence, no jitter), rAF frame-coalesced rendering, debounced ResizeObserver fixes the self-feedback loop.
- Container height adapts on mobile.

## Robustness

- **View data validation**: `useVaultData` validates that all five fields `nodes/edges/stats/tags/meta` are present, so corrupted data fails gracefully instead of crashing the whole page.
- **Uniform UTC date formatting**: eliminates the hydration mismatch caused by timezone differences between the SSR build machine and the browser.
- **Linearized dead-link pre-scan**: replaces the backtracking regex, so masses of malformed input like unclosed backticks no longer hang the scan.
- The dev asset middleware adds ETag / 304 conditional caching, and the basename fallback is tightened to avoid mismatches.

## Fixes

- Tags now cap single-line inline tags at 3 + a "+N" fold, so long titles are no longer squeezed out.
- When a cover image fails to load, the placeholder background color is now dark, keeping white text readable.
