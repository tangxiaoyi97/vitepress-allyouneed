# Guide overview

`vitepress-allyouneed` 把零散的 Obsidian / Notion 风格 vault 直接变成一个 VitePress 站点。完整 9 篇用户文档按顺序读:

## 🚀 上手(必读)

1. **[[install|Install]]** — 装包 + peer dependency
2. **[[configure|Configure]]** — 全部顶层配置参数细表

## 📖 参考(按需查)

3. **[[frontmatter|Frontmatter 完整字段表]]** — 一份表收齐所有可识别字段(DocHeader / sidebar / layout / theme ...)
4. **[[sidebar-auto|Sidebar 自动生成]]** — `sidebarAuto` 全部参数 + 4 种 recipe + 三种 layout
5. **[[sidebar-override|Sidebar 手动覆盖]]** — `_sidebar.md` 规范(frontmatter shape + markdown list 两种写法)
6. **[[doc-header|DocHeader]]** — 文档顶部 banner 的 frontmatter / themeConfig
7. **[[obsidian-syntax|Obsidian 语法]]** — callouts / 高亮 / 注释 / footnotes / block-refs / media embed

## 🛠 进阶

8. **[[custom-theme|Custom theme]]** — 主题覆盖三段论
9. **[[sidebar-recipes|Sidebar recipes]]** — 4 种典型 sidebar config 配方
10. **[[theme-interop|Theme interop & 样式覆盖]]** — 与第三方主题协作 + `--ayn-*` CSS 变量速查
11. **[[obsidian-compat|Obsidian 兼容性矩阵]]** — 哪些原生语法/插件已支持/部分/未支持

如果你只想"开箱跑起来",看完 1+2 就够。其它按需。
